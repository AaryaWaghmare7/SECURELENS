Research mode

A more thesis-friendly view of how SecureLens reasons about images.

This page is useful for demos, portfolios, and write-ups. It explains the detector signals, the current limitations, and the next improvements that would make the project feel even more serious.

Current emphasis
Frequency analysis
Shows repeating structure and high-frequency artifacts in the image.
Entropy and edges
Used as supporting signals when model votes are too close to call.
Metadata and quality
Resolution, file size, sharpness, blur, brightness, and contrast are tracked too.
Careful verdicts
Borderline images can be marked uncertain instead of mislabeled.

How the pipeline behaves

  • Image is uploaded and saved against the active user.
  • Several detector views and heuristic signals are combined.
  • The final result can be AI, REAL, or UNCERTAIN.
  • Metadata, quality, and heatmap evidence are bundled into the saved analysis.

What to improve next

  • Build a labeled validation set for more honest accuracy measurement.
  • Add calibration charts so confidence scores mean something measurable.
  • Compare results across more detectors and more image types.
  • Track batch and compare mode outputs alongside single-image analyses.
