Live capture Capture a frame and run SecureLens image analysis on it.

This captures a frame from your webcam and uses it as the upload image. The result still uses image evidence such as entropy, FFT, edge density, and compression signals.

How to use it
Start the camera, position the face or scene you want to analyze, and capture a frame. SecureLens will save that snapshot as a live capture and still compute the research signals around it.
