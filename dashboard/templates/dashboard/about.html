About SecureLens

A cleaner image trust project with a more polished story.

SecureLens is built to look like a real product instead of a class demo. It blends a friendlier interface with a cautious detector so borderline results do not get forced into the wrong bucket.

Try an analysis See the research view
Backend storage
Users
Stored in Django's auth tables inside the project database.
Analyses
Saved in the dashboard_imageanalysis table with prediction, confidence, and metadata.
Uploads
Stored in media/uploads/ during local development unless you change MEDIA_ROOT.

Where your data lives

Local development setup
DB

SQLite database

The default local database file is db.sqlite3 at the project root.

AU

User accounts

Login details and profile info sit in Django's built-in auth app tables.

UP

Uploaded images

Image files are written to the media folder so the history page can show them again later.

MD

Saved metadata

Extra analysis details are kept in analysis_meta for FFT, entropy, and model evidence.

Why it feels more polished

  • Soft layered gradients and floating particle motion.
  • Camera capture and gesture-to-emoji feedback for a more interactive demo.
  • Saved history and stats so the project feels like a full product rather than one screen.
